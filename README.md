# motorcycle-battery-pack

GEEKBMS 开源 **摩托车电池 PACK** 参考设计仓库。

当前为 **骨架占位**：下列路径已预留，文件多为空白占位，后续用真实工程文件替换即可。导航登记见 [Battery-PACK-Design-Hubs](https://github.com/GEEKBMS/Battery-PACK-Design-Hubs)。

## 目录约定

| 路径 | 用途 |
|---|---|
| `3d/` | 3D 结构（STEP / STL / 装配说明等） |
| `bom/` | BOM 清单 |
| `silkscreen/` | 丝印 / 标识相关文件 |
| `specs/` | 规格书 |
| `docs/` | 组装说明、注意事项等补充文档 |
| `releases/` | 本地暂存的发布包说明（正式包建议走 GitHub Releases） |

## 占位文件

各目录下的 `.gitkeep` 或 `PLACEHOLDER.md` 仅占位，**不是**可交付设计资料。替换真实文件后请删除占位说明，并更新本 README 的状态。
